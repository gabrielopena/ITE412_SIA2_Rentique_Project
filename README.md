## Project Objectives

The Rentique system aims to provide an online platform that makes renting suits and dresses more affordable, convenient, and reliable.

It will allow customers to browse available formal wear, check availability, and make rental reservations online. It will also help shop owners manage products, reservations, and rental records more efficiently.

## Project Scope

The system will cover customer registration, browsing of suits and dresses, viewing product details, checking availability, making reservations, and tracking rental status.

It will also allow shop owners to manage products, availability, reservations, and rental records, while administrators can monitor users and system activities.

The initial system will focus on online rental and reservation management. It will not cover physical delivery services or advanced payment gateway integration.

## Stakeholders

### Customers / Renters

Users who search for and rent suits and dresses.

### Shop Owners

Manage formal-wear products, availability, and reservations.

### System Administrator

Manages users and monitors the system.

### Rental Shop Staff

Assists with preparing, releasing, and receiving rented items.

## Project Summary

Rentique is a web-based suit and dress rental platform designed to improve the traditional process of renting formal wear. The platform allows customers to browse suits and dresses, view product details, check availability, choose rental dates, and make reservations online.

The system also provides shop owners and rental staff with tools for managing products, availability, reservations, and rental records. Administrators can monitor users and system activities.
